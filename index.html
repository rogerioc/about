Publications

Uma Comparação Preliminar entre Tecnologias para Implementação de Variabilidades em Jogos para Celulares 2008

SBGames, Belo Horizonte, MG, Brasil

Descreve-se e compara-se neste artigo um conjunto de tecnologias para implementação de variabilidades na área de jogos para celulares. Para isso, mostra-se um estudo de caso onde uma variabilidade de um jogo para celular foi implementada por meio de três tecnologias: compilação condicional, programação orientada por aspectos e programação orientada por features.

Extração de uma Linha de Produtos de Software na área de Jogos para Celulares usando Programação Orientada por Features 2008

II Latin American Workshop on Aspect-Oriented Software Development (LA-WASP), Campinas, SP, Brasil

This paper documents an experience in extracting a software product line in the domain of mobile phone games. The described product line has been implemented using feature-oriented programming, as supported by the AHEAD system. The paper also presents a quantitative and qualitative evaluation of the extracted product line and compares AHEAD with alternative technologies, notably with aspect-oriented programming.

Use of Aspect Oriented to specify device’s variability in Requirement of Motorola’s feature 2006

Universidade Federal de Pernambuco (UFPE), Recife, PE, Brasil

The purpose of this work is to present an effective technique for describing the variations of mobile phone within requirements using the Aspect Oriented paradigm, thus allowing an effective traceability control of related requirements, reducing the redundance, promoting the maintenance and facilitating new features creation.

Utilização de árvores B para armazenamento de dados no Palm OS 2006

IV Encontro Mineiro dos Estudantes de Computação (EMECOMP), Itajubá, MG, Brasil

Resumo: O Palm OS é um sistema operacional para dispositivo móvel que possui uma forma bastante primitiva de armazenamento de dados, já que sua estrutura é baseada em listas encadeadas. Sua eficiência é satisfatória até um determinado volume de dados, após este limite sua eficiência fica comprometida. Este trabalho tem o intuito de demonstrar uma nova forma de armazenamento de dados mais eficiente para o sistema Palm OS utilizando estrutura de dados árvores B.

Uma comparação de algoritmos e estruturas de dados para armazenamento de dados em sistemas operacionais Palm OS 2005

IV Simpósio De Informática da Região Centro do Rio Grande do Sul (SIRC/RS), Santa Maria, RS, Brasil

Resumo: Quando consideramos um sistema de banco de dados na plataforma Palm OS, nos deparamos com uma forma bastante primitiva de armazenamento de dados, já que sua estrutura é baseada em listas encadeadas. Sua eficiência é satisfatória até um determinado volume de dados, após o qual sua eficiência fica comprometida. Este trabalho tem o intuito de apresentar uma nova forma de armazenamento de dados, mais eficiente, para o sistema Palm OS. Para isso, duas estruturas de dados serão comparadas.
