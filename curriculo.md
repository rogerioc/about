## 📝 Publications

1. **[Uma Comparação Preliminar entre Tecnologias para Implementação de Variabilidades em Jogos para Celulares](https://www.sbgames.org/papers/sbgames08/computingtrack/short/cts22_08.pdf)** (2008)
   *SBGames, Belo Horizonte, MG, Brazil*
   > *Summary:* This paper describes and compares a set of technologies for implementing variabilities in the mobile games domain. A case study is presented where a mobile game variability was implemented using three technologies: conditional compilation, aspect-oriented programming, and feature-oriented programming.

2. **[Extração de uma Linha de Produtos de Software na área de Jogos para Celulares usando Programação Orientada por Features](https://drive.google.com/file/d/0BzIZOBGfuIwObm1xMzl6ckVUYmc/view)** (2008)
   *II Latin American Workshop on Aspect-Oriented Software Development (LA-WASP), Campinas, SP, Brazil*
   > *Summary:* This paper documents an experience in extracting a software product line in the domain of mobile phone games. The described product line has been implemented using feature-oriented programming, as supported by the AHEAD system. The paper also presents a quantitative and qualitative evaluation of the extracted product line and compares AHEAD with alternative technologies, notably with aspect-oriented programming.

3. **[Use of Aspect Oriented to specify device’s variability in Requirement of Motorola’s feature](https://drive.google.com/file/d/0BzIZOBGfuIwOcXMxTVozNUJYbjA/view)** (2006)
   *Universidade Federal de Pernambuco (UFPE), Recife, PE, Brazil*
   > *Summary:* The purpose of this work is to present an effective technique for describing the variations of mobile phone within requirements using the Aspect Oriented paradigm, thus allowing an effective traceability control of related requirements, reducing the redundance, promoting the maintenance and facilitating new features creation.

4. **[Utilização de árvores B para armazenamento de dados no Palm OS](https://drive.google.com/file/d/0BzIZOBGfuIwOeElVVWVyc2dMeW8/view)** (2006)
   *IV Mineiro Meeting of Computer Students (EMECOMP), Itajubá, MG, Brazil*
   > *Summary:* Palm OS is a mobile operating system that has a primitive data storage format, as its structure is based on linked lists. Its efficiency is satisfactory up to a certain data volume, after which its efficiency is compromised. This work aims to demonstrate a new, more efficient way of data storage for the Palm OS using B-tree data structures.

5. **[Uma comparação de algoritmos e estruturas de dados para armazenamento de dados em sistemas operacionais Palm OS](https://drive.google.com/file/d/0BzIZOBGfuIwOdXdqMlpOUER3eVE/view)** (2005)
   *IV Symposium of Informatics of the Central Region of Rio Grande do Sul (SIRC/RS), Santa Maria, RS, Brazil*
   > *Summary:* When considering a database system on the Palm OS platform, we face a very primitive form of data storage, since its structure is based on linked lists. Its efficiency is satisfactory up to a certain volume of data, after which its efficiency is compromised. This work aims to present a new, more efficient way of data storage for the Palm OS. To do this, two data structures are compared.
