# Rogério Celestino - Professional Portfolio

This repository contains the source code for my professional and academic portfolio. The website highlights my background in Mobile Software Engineering, AI & Data Science, academic publications, and certifications.

🔗 **Access the online portfolio:** [rogerioc.github.io/about](https://rogerioc.github.io/about/)

---

## 🚀 Technologies Used

- **HTML5** & **Vanilla CSS**
- **Outfit & Inter** (Google Fonts)
- **FontAwesome** (Social & informational icons)
- **Glassmorphism Design** with responsive layouts and subtle hover micro-animations

## 📂 Project Structure

- `index.html`: Main file containing both the structure and styling (CSS embedded in `<style>` for instant loading of the static page).

## 💻 How to Run Locally

Simply clone the repository and open the `index.html` file directly in your browser.
